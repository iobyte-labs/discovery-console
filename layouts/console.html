This console reads the private repository and starts its workflows. It stores no data of its own: the page you are reading is a static file with nothing in it, and everything you see is fetched live from GitHub with your own token. Without a token that can read that repository, this page shows nothing to anyone.

Left unticked, the token is held for this tab only and forgotten when you close it.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens and choose Generate new token (fine-grained).
  2. Resource owner: — the organisation, not your username.
  3. Repository access: Only select repositories → , and nothing else.
  4. Permissions: Contents → Read-only and Actions → Read and write.
  5. Give it the shortest expiry you can live with.

The token is sent only to api.github.com. This page loads no third-party script, so there is nothing here that could read it.
